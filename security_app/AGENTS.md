# Project notes for AI coding assistants

Read `docs/GUIDE.md` first: it explains the architecture, every file, and how deployment works.

- Deploy with the Databricks CLI and the `Dev` profile (OAuth U2M): `databricks bundle deploy -t dev -p Dev`.
- Never create Unity Catalog catalogs. Reporting uses the existing catalog in the `catalog` variable (dev: `dev_gold`).
- Edit `app/` only; `build/admin_app` is regenerated by the bundle's `preinit` script.
- Never edit an applied `sql/lakebase/NNN_*.sql` migration; add a new numbered file.
- Every state change goes through `app/cdp_security/service.py` in one transaction with an `audit.record` call.
- Run `pytest` before deploying.
